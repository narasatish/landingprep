## ⚠️ CRITICAL deploy model (misunderstanding this caused a 2-feature production outage)
- **Render's `buildCommand` is `npm install` — it does NOT run `npm run build`.** Render serves
  **exactly the files committed to git, as-is.** So every build output (`app-bundle.js`, all
  `screens/*.js`, `college-data.js`, `blog-data.js`, the prerendered `/**/index.html`, sitemap,
  `sw.js`) **must be built locally and committed.** If a generated file isn't committed, it 404s live.
- **You MUST run `npm run build` locally before committing** (it bumps `sw.js` CACHE_VERSION `lp-vNNN`
  + all `?v=` refs, regenerates SEO pages, runs the SEO audit which FAILS the build on broken links).
- `npm test` = hooks gate + exam validation + SEO audit + answer audit + IG tests (incl. slow
  `ig-full.test`) + **Playwright smoke (26 routes in real Chromium)**. Run it before every deploy.

## ⚠️ The lazy-data 404 trap (fixed this session — DO NOT re-trigger)
- `college-data.js` (College Predictor, `window.LP_COLLEGES`) and `blog-data.js` (in-app blog,
  `window.LP_BLOG`) are **lazy-loaded** (via `app-bundle.js`/colleges gate), NOT `<script src>` in
  index.html. `precompile-jsx.mjs` only re-transpiles a lazy module **if its `.js` sibling already
  exists** (the "sibling rule"). **If you `rm` one of these `.js` files before building, precompile
  SKIPS it, `git add -A` stages the deletion, and it 404s on production.** This is exactly what
  silently broke the College Predictor + blog from v385–v388.
- **NEVER `rm college-data.js` or `blog-data.js`.** (You may `rm` other `.js` that ARE `<script src>`
  in index.html — those regenerate from the index.html reference.)
- **Guardrail now in place:** `precompile-jsx.mjs` fails the build loudly if `college-data.js`,
  `blog-data.js`, or `seo-pages.js` is missing after transpile. If you need to regen one manually:
  `node --input-type=module -e "import{readFileSync,writeFileSync}from 'fs';import{transformSync}from 'esbuild';writeFileSync('X.js',transformSync(readFileSync('X.jsx','utf8'),{loader:'jsx',jsx:'transform',jsxFactory:'React.createElement',jsxFragment:'React.Fragment',target:'es2019'}).code)"`
