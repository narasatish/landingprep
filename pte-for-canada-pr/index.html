PTE Score for Canada PR — Requirements & Points

Since January 2024, IRCC accepts PTE Core for economic permanent-residence programs. PTE Core scores map to the Canadian Language Benchmarks (CLB).

The minimum you need

Aim for the PTE Core scores that correspond to CLB 7 in each skill — the common Express Entry minimum. Use the official PTE Core to CLB table for the exact numbers.

The competitive (high-points) target

PTE Core scores corresponding to CLB 9 in every skill earn the maximum CRS language points, the same target as IELTS or CELPIP CLB 9.

Why your score matters

PTE Core is computer-marked with fast results, so it is a strong option for raising your CLB and therefore your CRS score quickly.

Key tips

Use PTE Core (not PTE Academic) for Canadian economic immigration. Confirm the current PTE Core to CLB mapping and acceptance with IRCC.

Does Canada accept PTE for PR?
