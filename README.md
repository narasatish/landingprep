# Final Mock Test Bank v2

This package contains original pattern-based exam practice files.

Generated:
- 990 JSON test/mock files
- 11580 section questions/tasks
- 30 section tests for each section
- 30 full mock composition files for each exam

Key update:
- IELTS Listening now has 40 questions per test.
- IELTS Listening Part 2 varies across tests: map labelling, table completion, multiple choice, choose-two, matching, and sentence completion.
- Listening files include scripts and hidden internal voice config, but no user-facing voice names.
- Full mocks are lightweight composition files referencing section tests for fast loading.

Place `content/` in your public/root folder and load `/content/manifest.json`.
Do not import all JSON files into the main bundle.
